# GREEN check

The revised skill was tested against the same three scenarios.

- A multi-source policy request selects HTML, with a timeline as the primary view and evidence-backed causal/source details as secondary views.
- An explicit Markdown-only request stays in Markdown even when the prompt mentions visualization.
- A prose-only request does not receive invented numeric trends, scores, confidence intervals or forecasts. It may receive a qualitative timeline or evidence map, with data gaps visible.
- Urgency does not remove static, browser, keyboard or mobile checks.
- “Publish” remains blocked until the target host, domain, method, authorization boundary and rollback path are concrete.
- A long-text HTML request includes a readable full-text view in the DOM; the raw source box remains an optional appendix rather than the only copy.
- Claude-style and ASD-STE100-inspired rules apply to new explanatory copy only: the result uses direct, concrete Chinese without forced catchphrases, fake depth, unnecessary caveats or invented terminology.

The result closes the baseline loopholes without adding external runtime dependencies.
